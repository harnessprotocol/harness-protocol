# Harness Protocol

The Harness Protocol defines a vendor-neutral `harness.yaml` format for the complete operational context of an AI coding agent — plugins, MCP servers, environment requirements, behavioral instructions, and permissions.

AI coding tools like Claude Code, Cursor, and GitHub Copilot each have their own proprietary formats. A developer who crafts a well-tuned configuration for one tool cannot share it with a teammate on a different tool, publish it for their team to reuse, or carry it when they switch tools. The Harness Protocol defines a common format so harness configurations become portable, shareable artifacts — the same way MCP made tool communication portable.
