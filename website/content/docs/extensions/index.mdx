Extensions define how the Harness Protocol can grow beyond v1 without breaking existing implementations. The `x-` prefix reserves namespace for implementation-specific fields and future HEPs (Harness Enhancement Proposals). The v2 design sketches below are pre-HEP — they describe the intended direction for Exchange and Registry but are not yet normative.
